# Admin Panel

React admin panel for managing workspace users: list, search, filter, invite, create, edit, suspend, and delete.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Demo sign-in is prefilled on `/login`. User data is stored in memory for the session.

## Features

- User directory with search, role/status filters, pagination, and bulk status updates
- User profile, activity, and access controls
- Create, edit, invite, and delete users
- Roles, activity audit trail, and workspace settings
